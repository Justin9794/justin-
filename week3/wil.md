'array' 'map'.
뭐 하나 만들때마다 100개면, 코드도 100개..? 이건 아니지.. -> 1개의 array에 여러개의 게시글을 넣자!

데이터 1개 = Post 1개, 1대1 대응! ... 잠깐, 이럼 결국 의미 없는거 아냐?

그걸 해결하려고 map이 있는거다! (JavaScript, not react문법)
 
ex ) const posts =[{user:'justin',like:44},{user:'god',like:10}] (Array 제작)
posts(얘는 array임).map((post) => {<post username={post.user} like={post.like}/>}) (map형)

=> 이러면 1번째 입력받고 포스트 1개, 2번째 데이터보고 또 하나... 이렇게 만들 수 있다! 
(데이터 기준으로 만드는거라, 데이터가 늘어나면 화면도 같이 늘어난다! -> 복사 ㄴㄴ, 데이터를 화면으로 표현한 것!)

일전에 비하면 확실히 공부할 내용이 많은 것은 사실이었지만, 그만큼 무언가를 개발한다는 생각이 든 것도 사실이었다. 이번에 배운 component는 마치 파이썬의 def를 연상케 해서(여러 코드 축약 + 매개변수 같은 profs) 추후에 강력한 기능으로 사용될 것 같았다.
비록 array나 map의 경우, 난 아직 Js에 한해선 일반인 수준이어서 이해하는 데 시간이 필요할 것 같았지만, 언젠가는 잘 다루게 될 테니, 아무래도 좋았다. 
 또한, 데이터를 그대로 UI로 표현한다는 것이 새로운 발상이어서 신선하기도 했고, 확실히 어떻게 화면을 표현할 지 미리 정해져있으니 구현이 쉽다는 것을 알았다. 이제 다음시간에 배울 interaction을 적용하게 되면 그 탭을 좀 더 자유로이 꾸밀 수 있게 되니 기대가 되기도 한다.
